# LastLight 0.1.4

LastLight 0.1.4 is a focused reliability and public-contract hardening release.

## Highlights

- Preserves mounted pack name, version, source, and path on search results when a single explicit knowledge pack is used.
- Validates public `top_k` values consistently across `search()`, `query()`, `answer()`, and `plan()` instead of silently coercing invalid limits.
- Fails fast with `PackError` when the public `LastLight` facade receives a missing, empty, or unsupported explicit knowledge source.
- Prevents adaptive query-risk terms from matching inside unrelated words.
- Rejects invalid chunking limits instead of allowing non-terminating chunk generation.
- Handles valid JSON indexes with malformed top-level shapes without crashing.

The low-level repository and application-factory primitives remain available for internal tooling, while stricter validation is enforced at the stable public library boundary.

The runtime remains stdlib-only and requires no network connection once the Python package and knowledge packs are local.

After publication:

```bash
python -m pip install --upgrade lastlight
```
