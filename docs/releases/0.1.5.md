# LastLight 0.1.5

LastLight 0.1.5 is a runtime-hardening and retrieval-efficiency release focused on predictable public API failures, safer local packs, and better adaptive/BM25 behavior across real hardware.

## Highlights

- Rejects an explicitly empty pack collection instead of silently falling back to the built-in/default knowledge source.
- Validates adaptive energy and memory budgets at the stable `LastLight` boundary and reports invalid values through `ConfigurationError`.
- Validates provenance freshness windows at the public boundary instead of leaking internal `ValueError` behavior.
- Stops treating every `arm64`/`aarch64` host as low-resource solely because of CPU architecture, so Apple Silicon and server-class ARM64 machines can use BM25 when no real constraint is active. Termux, 32-bit ARM, survival mode, explicit budgets, and low battery continue to trigger the conservative path.
- Applies the same Markdown document-count, per-document size, and aggregate-size limits to directory packs that already protect ZIP packs.
- Rejects malformed runtime knowledge-source types through the public `PackError` hierarchy instead of exposing `tuple()`/`pathlib` `TypeError` exceptions.
- Reuses query-independent BM25 corpus statistics across repeated queries against unchanged content, with deterministic invalidation when ranked content changes.
- Removes superseded evaluation artifacts after the core regression corpus moved into the installed `lastlight.evaluation` package.

## Compatibility

The runtime remains Python-standard-library-only and supports Python 3.10, 3.11, and 3.12. Pack Format v1 is unchanged. Existing `LastLight.query()`, `search()`, `answer()`, `plan()`, pack inspection, validation, and provenance contracts remain available.

The BM25 optimization does not introduce a persistent index or stale-pack policy: repositories may still reload local documents, while query-independent ranking preparation is reused only when the ordered corpus content is equivalent.

## Upgrade

```bash
python -m pip install --upgrade lastlight
```
