# LastLight 0.3.0

This release separates raw ranking from a configurable, auditable acceptance
policy and adds deterministic, offline `hybrid` retrieval.

Highlights:
- BM25/lexical RRF hybrid without direct numeric score fusion.
- Configurable section/chunk bounds, preserved source paths and heading provenance.
- Public per-backend calibration policy and explainable, bounded evidence scores.
- Machine-readable refusal codes, with backward-compatible legacy reasons.
- More candidate verification when adaptive accuracy has available resources.
- English/Spanish normalization and stable offline search.

No additional runtime dependencies. Python >=3.10 remains supported.

Safety disclaimer: LastLight only retrieves local text and evaluates heuristic
signals. It cannot verify real-time, confidential, privileged or future facts.

The independent lastlight-bench project has not been modified. In the
pre-release external diagnostic, BM25 answerable recall improved relative
to 0.2.2, while false acceptance also increased, so this release does
**not** claim to meet the original refusal or precision objectives. Consumers
should inspect evidence and refusal codes and perform their own validation
for critical applications.
