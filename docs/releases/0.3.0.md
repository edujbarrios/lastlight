# LastLight 0.3.0 — prepared release notes (NOT PUBLISHED)

This candidate separates raw ranking from a configurable, auditable acceptance
policy and adds deterministic, offline `hybrid` retrieval.

Highlights:
- BM25/lexical RRF hybrid without direct numeric score fusion.
- Configurable section/chunk bounds, preserved source paths and heading provenance.
- Public per-backend calibration policy and explainable, bounded evidence scores.
- Machine-readable refusal codes, with backward-compatible legacy reasons.
- More candidate verification when adaptive accuracy has available resources.
- English/Spanish normalization and stable offline search.

No additional runtime dependencies. Python >=3.10 remains supported.

Safety disclaimer: LastLight only retrieves local text and evaluates heuristic
signals. It cannot verify real-time, confidential, privileged or future facts.

**Publication gate**: the source tree has been versioned 0.3.0, but there is no
published PyPI 0.3.0 release yet. Full CI/package checks must pass, and the
maintainer must grant explicit release approval before creating a version tag,
publishing a GitHub Release or invoking the production PyPI workflow.
The independent lastlight-bench project is intentionally left untouched.
An earlier diagnostic evaluation of this feature branch was mixed and is
not a release-quality benchmark for the final commit; no benchmark quality
target or safety-performance guarantee is claimed.
