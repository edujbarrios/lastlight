# LastLight 0.1.3

LastLight 0.1.3 hardens the core contracts that companion repositories will depend on.

## Highlights

- Ships a packaged deterministic core evaluation suite with answerable and expected-refusal cases.
- Adds CI regression gates for top-1 accuracy, answer precision, refusal recall, and answerable recall.
- Defines and validates LastLight Knowledge Pack Format v1 via `format_version: 1`.
- Uses canonical pack-relative document paths so equivalent directory and ZIP packs have stable identities.
- Makes directory and ZIP representations feed the same logical paths into pack fingerprints.
- Rejects unsafe ZIP paths and duplicate normalized members.
- Adds limits for ZIP Markdown entry size, total uncompressed Markdown size, document count, and manifest size.
- Wraps malformed pack reads in the public `PackError` hierarchy.

The runtime remains stdlib-only and requires no network connection once the Python package and knowledge packs are local.
