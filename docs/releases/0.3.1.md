# LastLight 0.3.1 — Maintenance release

LastLight 0.3.1 is a conservative maintenance release. The installed library
retains the **same offline retrieval and answer/refusal behavior** as 0.3.0.
The public Python API and Python >=3.10 compatibility are unchanged.

## Changes

- Added a **read-only v4 dataset readiness check** to the source repository.
  It verifies the external benchmark's document and labeled-query counts,
  language and answerability breakdown, Git commit, and SHA-256 fingerprints.
  The check fails closed when the available data does not match the required v4
  dataset instead of silently substituting an older dataset.
- Added source-tree tooling for a controlled comparison of separately installed
  LastLight 0.2.2 and 0.3.0 versions on identical data, using the external
  benchmark's metrics unchanged.
- Added a separate deterministic audit for answerable queries whose expected
  document ranks first but the library refuses, recording the public decision
  evidence and refusal metadata.
- Added offline regression tests and GitHub Actions support for the v4
  readiness/preflight tools.
- Added an English-language 0.4.0 implementation and release-validation
  roadmap.
- Updated README installation instructions and dynamic PyPI/GitHub release
  badges so users can discover the published package version.

The research tools are available in the GitHub source repository under
`tools/`. They are **not runtime modules or CLI entry points in the PyPI
wheel**, and they do not change the benchmark repository.

## Evaluation limitations

At the time of this release, the public `lastlight-bench` checkout has 32
documents and 160 labeled queries, whereas the requested corpus v4 contains
44 documents and 240 queries. Therefore **the v4 baseline, controlled
comparison, and 0.4.0 engineering targets remain unverified**. Neither new
accuracy nor safety nor latency improvements are claimed for 0.3.1.

Safety disclaimer: LastLight only retrieves locally supplied text and applies
deterministic heuristic acceptance checks. It cannot establish private,
real-time, future, or privileged facts. Verify any operational instructions
with qualified authorities and authoritative local guidance.

## Install

```bash
python -m pip install --upgrade lastlight==0.3.1
```
