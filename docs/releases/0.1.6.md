# LastLight 0.1.6

LastLight 0.1.6 improves retrieval from long, structured Markdown guides while preserving the small, auditable, standard-library-only core.

## Highlights

- Parses ATX Markdown headings (`#` through `######`) into deterministic retrieval sections while preserving the heading hierarchy.
- Ignores heading-like text inside fenced code blocks, retains pre-heading prose, and omits empty structural parent sections.
- Automatically switches sufficiently large structured guides to section-level scoring instead of diluting relevance across the entire file.
- Keeps short documents on the existing document-level scoring path for compatibility with established scores and confidence thresholds.
- Uses heading paths as weighted retrieval titles for both lexical and BM25 ranking.
- Returns the original Markdown document as the public source even when an internal section wins ranking, preserving stable source paths, pack metadata, provenance, and caller contracts.
- Collapses multiple matching sections from the same guide to the best source result so one large manual does not crowd out other sources in `top_k` results.
- Keeps BM25 query-independent corpus caching compatible with the new section-level scoring units.
- Adds regression coverage for long first-aid-style Markdown manuals in lexical and BM25 retrieval.

## Large-guide behavior

For small Markdown files, retrieval behavior is unchanged. For a structured document of at least 4,000 characters with multiple non-empty Markdown sections, LastLight scores the sections independently and extracts the final passage from the winning section.

A manual such as:

```markdown
# First Aid Field Guide

## Burns
...

## Severe bleeding

### Tourniquet use
...
```

is therefore ranked using the relevant heading path and local section content rather than treating the complete manual as one flat BM25/lexical document.

This is intentionally structural rather than arbitrary fixed-size chunking: source documents remain human-readable and auditable, and public results continue to identify the original file.

## Compatibility

The public `LastLight` API and Knowledge Pack Format v1 are unchanged. Existing packs do not need to be rebuilt. Python 3.10, 3.11, and 3.12 remain supported and there are still no runtime dependencies outside the Python standard library.

## Upgrade

```bash
python -m pip install --upgrade lastlight
```
