# LastLight 0.1.9

LastLight 0.1.9 extends the repeated-query efficiency work from 0.1.8 down into the knowledge-repository layer. Unchanged packs no longer pay repeated document I/O, ZIP decompression, manifest parsing, or multi-pack document decoration on every query.

## Highlights

- Caches parsed `KnowledgeDocument` values inside `MarkdownKnowledgeRepository` while the underlying pack snapshot is unchanged.
- Uses lightweight ZIP file metadata to reuse unchanged archive contents instead of reopening, decompressing, decoding, front-matter parsing, and hashing every Markdown document for each query.
- Keeps directory packs hot-reloadable with deterministic file metadata fingerprints covering paths, sizes, modification times, and change times.
- Detects additions, removals, renames, and normal edits in directory packs while avoiding rereads of unchanged Markdown bodies.
- Avoids retaining a repository cache entry when a pack changes while its documents are being read.
- Caches directory-manifest and ZIP pack metadata from `describe_pack()` with automatic fingerprint-based invalidation.
- Reuses inferred pack metadata while the underlying document snapshot remains unchanged.
- Caches the decorated document snapshot produced by `CompositeKnowledgeRepository`, avoiding repeated `dataclasses.replace()` allocation across unchanged multi-pack corpora.
- Returns fresh list containers from repository caches so caller-side filtering cannot mutate cached internal state.
- Adds regressions for directory and ZIP document cache reuse, cache invalidation, pack metadata invalidation, and composite snapshot rebuilding.

## Repeated-query path

For an unchanged ZIP knowledge pack, the hot path now reuses preparation at four layers:

1. parsed Markdown documents and source hashes;
2. parsed pack manifest metadata;
3. composed multi-pack document metadata;
4. retrieval units plus lexical or BM25 ranking statistics.

Large-document passage extraction remains deferred until final ranking winners are known. The result is a substantially smaller amount of repeated pure-Python work for interactive sessions that ask many questions against the same local pack.

Directory packs deliberately retain a lightweight metadata scan on each repository access so a locally edited knowledge tree can still refresh automatically. This scan does not reread unchanged document bodies.

## Compatibility

The public `LastLight` API, retrieval scores, confidence thresholds, result types, refusal behavior, Knowledge Pack Format v1, and large-document ranking behavior are unchanged. Existing packs do not need to be rebuilt. Python 3.10, 3.11, and 3.12 remain supported, and the runtime still has no dependencies outside the Python standard library.

## Upgrade

```bash
python -m pip install --upgrade lastlight
```
